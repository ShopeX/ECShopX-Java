A code wiki for ECShopX-Java (cn.shopex:ecshopx): Spring Boot 3 + Java 17 multi-module commerce backend. One business domain = one Maven Bundle; ecshopx-bootstrap is the single Spring Boot entry that assembles Bundles. Business semantics and config map closely to the legacy PHP ECShopX.Focus on:- Architecture: parent POM / BOM, Bundle layering (controller / service / mapper / integration / port), cross-Bundle Ports via ecshopx-common + ecshopx-dispatch- Core domains: goods, orders, aftersales, members, promotions / kaquan / point / pointsmall, merchant / store / salesperson / selfservice, payment channels, wechat / work-wechat, openapi, third-party (ali / shuyun / system-link / youshu), cross-border- Runtime & ops: Flyway under ecshopx-bootstrap, multi Redis DBs, XXL-JOB, Undertow (PHP URL compatibility), docker / docker-lite / compose, install & deploy scripts- Change guidance: where APIs live per Bundle, dependency boundaries, migration workflow (bin/make-migration)Skip: target/, .flattened-pom.xml, large docker SQL dumps / seed data, logos/media, local logs/.
